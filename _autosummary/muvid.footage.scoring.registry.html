muvid.footage.scoring.registry¶

The scorer registry: what a metric IS, so adding one touches no orchestrator code (muvid#19).

A scorer turns one clip (plus the shared, compute-once-on-master artifacts) into ScoreTracks on the song grid. The orchestrator used to call three extractors by name and keep a hardcoded metric tuple, so a new scorer meant editing four places and metrics= could only filter what those calls produced. Now it walks this registry — the house idiom (register_visual, register_selection_strategy, register_aligner) — and the metric axis, the default metric set and the wanted-set filter are all derived from the rows.

A scorer is handed a ClipContext and returns tracks. It declares:

  • metrics — the names it produces (a metrics= request is matched against them);

  • needs_frames — whether it reads the shared decode pass (one decode per clip, however many scorers read it: the design review’s fix for the double decode);

  • gated — whether the optional hard quality gate is ANDed into its masks;

  • tier — "core" (the commercial-clean default) or "lipsync" (the opt-in, off-prod tier of the licence boundary in the repo guide). A new scorer is "core" only if every dependency it brings is MIT/BSD/Apache/ISC.

Absent is not zero. A scorer that could not measure a frame returns the frame masked (NaN raw, False mask), never 0.0: the composite renormalises over the weight that was available (muvid#19), and a 0.0 would count as the worst possible score.

Import-safe: this module is stdlib-only; every built-in’s heavy import lives inside its run function. A registered metric weighs 0 in the weighted selector until a caller gives it a weight (weights={"my_metric": 0.3}) — registering changes what is measured and shown, never what an existing edit selects.

Bases: object

What a scorer is handed for ONE clip. Paths and primitives, never the project.

frames is the shared decode pass (None when no selected scorer declares needs_frames); beat is the master beat grid; vocal_stem the master vocal stem path (None unless the lip-sync tier is running); grid is {"t0", "hop_s", "n"}.
